# תוכנית יישום: אנשי קשר מאוחדים

## סקירה כללית

יישום מאפיין "אנשי קשר מאוחדים" שמאחד את כל האנשים במערכת הגמ"ח (לווים, ערבים, תורמים, מפקידים) לתצוגה מרכזית אחת. המימוש כולל יצירת שירות חדש `contactsService`, טבלת `contacts` חדשה, ורכיבי UI להצגה וניהול של אנשי קשר.

## הערות

- משימות המסומנות ב-`*` הן אופציונליות וניתן לדלג עליהן לצורך MVP מהיר יותר
- כל משימה מתייחסת לדרישות ספציפיות לצורך מעקב
- Checkpoints מבטיחים אימות הדרגתי
- בדיקות תכונות מאמתות נכונות אוניברסלית
- בדיקות יחידה מאמתות דוגמאות ספציפיות ומקרי קצה
- כל הטקסטים חייבים להיות דרך מפתחות תרגום i18n
- אין להשתמש באימוג'ים - רק באייקונים מ-lucide-react
