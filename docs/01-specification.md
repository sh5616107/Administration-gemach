# מסמך אפיון - מערכת ניהול גמ"ח כספים

## סקירה כללית

### מטרת המערכת
מערכת לניהול גמ"ח כספים המיועדת למחשבי Windows, עם ממשק מודרני וחדשני.

### טכנולוגיות נבחרות
- **Frontend**: React 18 + Material-UI (MUI) v5
- **Desktop Framework**: Electron
- **Database**: SQLite (better-sqlite3)
- **תאריכים עבריים**: hebcal
- **הפקת מסמכים**: jsPDF + html2canvas
- **שפה**: TypeScript

---

#### טאב ג': ניהול הלוואות

##### בחירת הקשר
1. בחירת לווה (חובה)
2. בחירת הלוואה קיימת / הלוואה חדשה

##### טופס הלוואה
| שדה | תיאור |
|-----|-------|
| סכום ההלוואה | מספר בש"ח |
| תאריך מתן | תמיכה בתאריך עברי ולועזי |
| סוג הלוואה | קבועה (עם תאריך פירעון) / גמישה |
| תאריך החזרה | תמיכה בתאריך עברי |
| הערות | אופציונלי |
| ערב ראשון | בחירה מרשימה |
| ערב שני | בחירה מרשימה |

##### הלוואה מחזורית
- מספר חודשים
- יום בחודש להתחלה
- אם היום עבר - דחייה לחודש הבא (עם הודעה)
- בדיקה בפתיחת התוכנה להלוואות חדשות

##### פירעון אוטומטי
- סכום פרעון חודשי
- יום בחודש לפרעון
- תאריך תחילת פירעון
- תדירות: חודשי / דו-חודשי / רבעוני

##### כפתורי פעולה
- שמור הלוואה
- הלוואה חדשה
- הוסף פירעון (לא יותר מסך ההלוואה)
- פירעון מרובה (לכמה הלוואות)
- הפק שטר
- הפק שטר ריק
- עריכה מתקדמת (מחיקה, שינוי ערכים)

##### שטר הלוואה - תבנית
```
[לוגו הגמ"ח]

שטר הלוואה

אני הח"מ [שם הלווה] מאשר בזה כי לוויתי מגמ"ח "[שם הגמ"ח]"
סכום של: [סכום] ש"ח
בתאריך: [תאריך לועזי] ([תאריך עברי])

אני מתחייב להחזיר את הסכום לפי התראה

תאריך הפקת השטר: [תאריך]

חתימת הלווה: ________________

[אם יש ערבים:]
חתימת ערב 1 ([שם]): ________________
חתימת ערב 2 ([שם]): ________________
```

##### סוגי הלוואות
- **הלוואה פעילה** - תאריך עבר, לא נפרעה
- **הלוואה מתוכננת** - תאריך עתידי
- **הלוואה מחזורית** - סימון מיוחד
