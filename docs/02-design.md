## פלטת צבעים

### צבעים ראשיים
```css
--primary: #1976d2;        /* כחול ראשי */
--primary-dark: #115293;   /* כחול כהה */
--primary-light: #4791db;  /* כחול בהיר */
--secondary: #9c27b0;      /* סגול משני */
```

### צבעי סטטוס
```css
--success: #2e7d32;        /* ירוק - הצלחה */
--warning: #ed6c02;        /* כתום - אזהרה */
--error: #d32f2f;          /* אדום - שגיאה */
--info: #0288d1;           /* כחול - מידע */
```

### צבעי רקע
```css
--background: #f5f5f5;     /* רקע כללי */
--surface: #ffffff;        /* כרטיסים */
--surface-variant: #fafafa; /* רקע משני */
```

## אנימציות ומעברים

### מעברי עמודים
- Fade in: 200ms ease-in-out
- Slide: 300ms ease-out

### אינטראקציות
- Hover על כפתורים: scale(1.02), 150ms
- Hover על שורות טבלה: background-color, 100ms
- פתיחת מודל: fade + scale, 200ms

### טעינה
- Skeleton loading לטבלאות
- Spinner לפעולות ארוכות
- Progress bar לייצוא/ייבוא

## Responsive Design

### נקודות שבירה
- Desktop: > 1200px (מלא)
- Tablet: 768px - 1200px (מותאם)
- Mobile: < 768px (לא נתמך - הודעה למשתמש)

### התאמות Tablet
- תפריט צד מתכווץ
- טבלאות עם גלילה אופקית
- טפסים בעמודה אחת
