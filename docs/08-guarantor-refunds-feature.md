# פיצ'ר החזרים לערבים

## תיאור
מערכת לניהול החזרים מהלווה לערב במקרים שבהם הערב שילם את החוב והלווה מחזיר לו את הכסף.

## הבעיה שנפתרה
כאשר הלוואה מועברת לערב והערב משלם, ולאחר מכן הלווה משלם בחזרה את החוב, היה סימון שמגיע החזר לערב אך לא הייתה דרך לעקוב אחרי:
- כמה הוחזר לערב
- מתי הוחזר
- באיזה אמצעי תשלום
- האם הוחזר במלואו או חלקית

## הפתרון

### 1. מבנה נתונים חדש
- **GuarantorRefund** - טבלה חדשה לעקוב אחרי החזרים לערב
  - `id` - מזהה ייחודי
  - `guarantor_loan_id` - קישור להלוואת הערב
  - `amount` - סכום ההחזר
  - `refund_date` - תאריך ההחזר
  - `payment_method` - אמצעי תשלום
  - `payment_details` - פרטי תשלום (JSON)
  - `notes` - הערות
  - `created_at` - תאריך יצירה

- **שדה חדש ב-GuarantorLoan**:
  - `total_refunded` - סה"כ הוחזר לערב

### 2. שירותים
- `guarantorRefundsService` - שירות לניהול החזרים
  - `getAll()` - קבלת כל ההחזרים
  - `getByGuarantorLoan(guarantorLoanId)` - החזרים לפי הלוואת ערב
  - `getTotalRefunded(guarantorLoanId)` - סה"כ הוחזר
  - `create(refund)` - יצירת החזר חדש
  - `update(id, data)` - עדכון החזר
  - `delete(id)` - מחיקת החזר

### 3. ממשק משתמש

#### דיאלוג ניהול החזרים (`GuarantorRefundDialog`)
- **מידע כללי**:
  - שם הערב
  - שם הלווה
  - סכום ששילם הערב
  - סה"כ הוחזר לערב
  - נותר להחזיר

- **טופס הוספת החזר**:
  - סכום
  - תאריך
  - אמצעי תשלום (עם פרטים מלאים)
  - הערות

- **טבלת החזרים**:
  - רשימת כל ההחזרים
  - אפשרות לעריכה ומחיקה

#### אינטגרציה בטאב ערבים
- **כפתור חדש** בטבלת הלוואות הערבים:
  - מופיע רק כאשר יש סימון "מגיע החזר לערב"
  - אייקון בולט (AccountBalance) בצבע אדום
  - פותח את דיאלוג ניהול ההחזרים

### 4. ולידציות
- לא ניתן להחזיר יותר מהסכום ששילם הערב
- בדיקת סכומים תקינים
- עדכון אוטומטי של `total_refunded` בהלוואת הערב

### 5. Migration
- Migration v8 מוסיף את השדה `total_refunded` להלוואות ערב קיימות
- אתחול ערך ברירת מחדל: 0

## שימוש

### הוספת החזר לערב
1. עבור לטאב "ערבים"
2. גלול לטבלת "הלוואות שהועברו לערבים"
3. מצא הלוואה עם סימון "⚠️ מגיע החזר"
4. לחץ על כפתור ההחזרים (אייקון בנק אדום)
5. לחץ "הוסף החזר"
6. מלא את הפרטים:
   - סכום
   - תאריך
   - אמצעי תשלום
   - הערות
7. לחץ "הוסף"

### צפייה בהיסטוריית החזרים
- פתח את דיאלוג ההחזרים
- טבלה מציגה את כל ההחזרים שבוצעו
- ניתן לערוך או למחוק החזרים קיימים

### מעקב אחרי יתרה
- הדיאלוג מציג:
  - סכום ששילם הערב
  - סה"כ הוחזר
  - נותר להחזיר
- צבעים:
  - ירוק - הוחזר במלואו
  - אדום - עדיין נותר להחזיר
