## ✨ שיפור 2: כפתור "רענן דף"

### מה הוספתי?

#### בממשק:
```tsx
<Box display="flex" gap={2}>
  <Button /* הרץ אבחון */>
  
  <Button
    variant="outlined"
    color="secondary"
    onClick={() => window.location.reload()}
    startIcon={<RefreshIcon />}
  >
    רענן דף
  </Button>
</Box>
```

#### הודעה:
```
💡 טיפ: אם הוספת לווה/הלוואה חדשים, רענן את הדף (F5) לפני הרצת האבחון.
```

### למה זה חשוב?

**התרחיש:**
1. אתה בעמוד אבחון
2. הולך ל"לווים" → מוסיף לווה חדש
3. חוזר לאבחון
4. הרץ אבחון → **לא רואה את הלווה החדש!** ❌

**למה?**
הדאטה נטען ל-memory כש**הדף נפתח**.  
כשמוסיפים לווה, הוא נשמר ב-localStorage, אבל **memory לא מתעדכן**.

**הפתרון:**
- לחץ **"רענן דף"** או **F5**
- זה טוען את הדאטה מחדש מ-localStorage
- עכשיו האבחון רואה את הלווה החדש! ✅
