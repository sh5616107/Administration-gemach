## 📊 מה כל שלב בודק?

### שלב 1: עסקאות ללא התאמה
**בודק:** יש עסקאות בנק שעדיין לא הותאמו?

**תוצאות אפשריות:**
- ✅ **"נמצאו X עסקאות"** = יש עסקאות, מעולה!
- ❌ **"לא נמצאו עסקאות"** = צריך לסנכרן בנק

**אם יש בעיה:**
1. לך ל**"שילוב בנקים > סנכרון"**
2. לחץ **"התחל סנכרון"**
3. חזור לאבחון

---

### שלב 2: לווים במערכת
**בודק:** יש לווים במערכת?

**תוצאות אפשריות:**
- ✅ **"נמצאו X לווים"** = יש לווים, טוב!
- ❌ **"לא נמצאו לווים"** = צריך להוסיף לווים

**אם יש בעיה:**
1. לך ל**"לווים והלוואות"**
2. לחץ **"+ לווה חדש"**
3. הוסף לווה
4. חזור לאבחון

---

### שלב 3: הלוואות פעילות
**בודק:** יש לווים עם חוב פתוח (יתרה > 0)?

**תוצאות אפשריות:**
- ✅ **"X לווים עם הלוואות פעילות"** = יש חובות פתוחים!
- ❌ **"אין לווים עם הלוואות פעילות"** = כל החובות נסגרו

**אם יש בעיה:**
1. לך ל**"לווים והלוואות"**
2. בחר לווה
3. לחץ **"הלוואה חדשה"**
4. צור הלוואה
5. חזור לאבחון

---

### שלב 4: תאימות
**בודק:** עסקה ראשונה vs לווה ראשון - יש התאמה?

**מה זה בודק:**
- הפרש סכומים
- הפרש תאריכים
- ציון התאמה

**תוצאות אפשריות:**
- ✅ **"ציון X/115 - התאמה תיווצר"** = הציון מספיק (≥50)
- ⚠️ **"ציון X/115 - לא מספיק"** = הציון נמוך מדי (<50)

**מידע שתראה:**
```json
{
  "transaction": {
    "amount": 250,
    "date": "2024-01-15",
    "description": "העברה",
    "memo": "המבצע: משה כהן."
  },
  "borrower": {
    "name": "משה כהן",
    "phone": "0501234567",
    "remaining": 250,
    "loanDate": "2024-01-15"
  },
  "analysis": {
    "amountDiff": "0.00",
    "daysDiff": 0,
    "score": 95,
    "reasons": [
      "סכום זהה (35)",
      "תאריך זהה (25)",
      "כיוון נכון (5)"
    ]
  }
}
```

**תוצאות אפשריות:**
- ✅ **"המערכת מוכנה ליצירת התאמות"** = הכל תקין!
- ❌ **"בעיות: ..."** = יש בעיות שצריך לפתור

## 🐛 פתרון בעיות נפוצות

### בעיה: "לא נמצאו עסקאות ללא התאמה"
**פתרון:**
```
1. לך ל: שילוב בנקים > סנכרון
2. לחץ: התחל סנכרון
3. חכה שהסנכרון יסתיים
4. חזור לאבחון
```

---

### בעיה: "לא נמצאו לווים במערכת"
**פתרון:**
```
1. לך ל: לווים והלוואות
2. לחץ: + לווה חדש
3. מלא פרטים: שם, טלפון
4. שמור
5. חזור לאבחון
```

---

### בעיה: "אין לווים עם הלוואות פעילות"
**פתרון:**
```
1. לך ל: לווים והלוואות
2. בחר לווה
3. לחץ: הלוואה חדשה
4. מלא: סכום, תאריך
5. שמור
6. חזור לאבחון
```

---

### בעיה: "ציון נמוך מדי - לא מספיק"
**מה זה אומר:**
הסכומים או התאריכים לא תואמים מספיק.

**פתרון:**
בדוק ב-"פרטים" את:
- `amountDiff` - הפרש הסכומים
- `daysDiff` - הפרש התאריכים
- `reasons` - מה נתן ציון ומה לא

**דוגמאות:**
```
✅ טוב: amountDiff: "0.00", daysDiff: 0, score: 95
⚠️ בינוני: amountDiff: "5.50", daysDiff: 2, score: 55
❌ רע: amountDiff: "150.00", daysDiff: 20, score: 0
```

**איך לשפר:**
1. **סכומים לא תואמים?**
   - בדוק שהסכום בעסקת בנק = יתרת החוב
   - אולי זה פירעון חלקי? (צריך ≥10% מהיתרה)

2. **תאריכים רחוקים?**
   - סנכרן בנק לעתים קרובות יותר
   - כל הלוואה חדשה = סנכרן מיד

3. **ציון נמוך בכל זאת?**
   - הוסף `memo` לעסקת בנק עם שם הלווה
   - הוסף טלפון ללווה (20 נקודות!)
