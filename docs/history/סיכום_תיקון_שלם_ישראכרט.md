- הכסף **יצא** מחשבון הגמ"ח (סכום שלילי)
- התאריך תואם למתן ההלוואה (לא לפירעון עתידי)

## התיקונים שבוצעו

### ✅ תיקון 1: זיהוי מתן הלוואות (Frontend)
**קובץ:** `src/pages/bank/BankDebugPage.tsx`

#### שינוי א': בדיקת סכום כפולה
```typescript
// לפני: רק מול היתרה
const amountDiff = Math.abs(Math.abs(txn.amount) - loan.remaining);

// אחרי: גם מול סכום מקורי וגם מול יתרה
const amountDiffRemaining = Math.abs(Math.abs(txn.amount) - loan.remaining);
const amountDiffOriginal = Math.abs(Math.abs(txn.amount) - loan.amount);
const amountDiff = Math.min(amountDiffRemaining, amountDiffOriginal);
const isCheckingOriginal = amountDiffOriginal < amountDiffRemaining;
```

**תוצאה:** זיהוי אם זו מתן הלוואה (קרוב לסכום מקורי) או פירעון (קרוב ליתרה).

#### שינוי ב': כיוון דינמי
```typescript
// לפני: תמיד ציפיה ל-"in"
const expectedDirection = 'in';

// אחרי: דינמי לפי סוג העסקה
const isLoanDisbursement = actualDirection === 'out' && 
  Math.abs(Math.abs(txn.amount) - loan.amount) < Math.abs(Math.abs(txn.amount) - loan.remaining);

const expectedDirection = isLoanDisbursement ? 'out' : 'in';
```

**תוצאה:** +5 נקודות על כיוון עבור מתן הלוואות.

#### שינוי ג': הודעות ברורות
```typescript
reasons.push(isLoanDisbursement 
  ? 'כיוון נכון - מתן הלוואה (5)' 
  : 'כיוון נכון - פירעון (5)');

const amountLabel = isCheckingOriginal ? 'מתן הלוואה' : 'יתרה';
reasons.push(`סכום קרוב - ${amountLabel} (20)`);
```

**תוצאה:** הפלט מראה בדיוק מה סוג ההתאמה.

### ✅ תיקון 2: חילוץ שמות מ-description (Backend)
**קובץ:** `src-tauri/src/bank_integration.rs`

#### הבעיה:
הקוד חילץ שמות מ-description **רק** אם תואם regex מורכב:
- "מ-<שם>"
- "מאת <שם>"
- "<שם> העביר"
- וכו'

אבל "ישראכרט" פשוט לא תואם אף דפוס!

#### הפתרון - Fallback חכם:
```rust
// אם לא חילצו שום שם עד עכשיו
if extracted_names.is_empty() && !description.is_empty() {
    // בדוק אם זה נראה כמו שם (אותיות עבריות, אורך סביר)
    let hebrew_chars = description.chars()
        .filter(|c| ('\u{0590}'..='\u{05FF}').contains(c))
        .count();
    let total_chars = description.chars()
        .filter(|c| !c.is_whitespace())
        .count();
    
    // אם לפחות 50% עברית ואורך 2-40 תווים
    if hebrew_chars as f64 / total_chars as f64 >= 0.5 && 
       cleaned_desc.len() >= 2 && 
       cleaned_desc.len() <= 40 {
        // לא מילת מפתח נפוצה ("העברה", "תשלום" וכו')
        if !is_excluded {
            extracted_names.push(cleaned_desc.to_string());
        }
    }
}
```

**תוצאה:** "ישראכרט" מזוהה כשם גם בלי פורמט מיוחד!

```json

      "סכום קרוב - מתן הלוואה (20)",
      "תאריך זהה (20)",
```

## מה למדנו?

### 1. עסקאות בנק יכולות להיות בשני כיוונים
- **כניסה (+):** פירעונות, תרומות, הפקדות
- **יציאה (-):** מתן הלוואות, הוצאות, משיכות

### 2. חילוץ שמות צריך fallback
לא כל שם מופיע בפורמט מובנה. צריך fallback פשוט:
- אם זה עברית
- אם זה באורך סביר
- אם זה לא מילת מפתח נפוצה
- → השתמש בזה כשם!

### 3. אבחון מקומי חשוב
כלי האבחון עזר לזהות בדיוק איפה הבעיה:
- הציון היה 40 במקום 50
- חסרו 10 נקודות - 5 על כיוון, 5 על שם
- זה הוביל ישירות לפתרון
