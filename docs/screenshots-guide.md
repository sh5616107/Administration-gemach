# 📸 מדריך צילומי מסך למדריך המשתמש

מסמך זה מכיל הוראות מדויקות לצילום כל אחד מ-16 צילומי המסך הנדרשים למדריך המשתמש.

---

## הוראות כלליות

1. **רזולוציה**: צלם במסך מלא או בחלון מקסימלי
2. **איכות**: שמור בפורמט PNG לאיכות מיטבית
3. **שמות קבצים**: שמור את הקבצים בשמות המפורטים למטה
4. **מיקום**: שמור את כל הקבצים בתיקייה `docs/images/`
5. **נתונים**: השתמש בנתונים לדוגמה (לא נתונים אמיתיים!)
6. **שפה**: וודא שהממשק בעברית

---

## צילום מסך 1: מסך הכניסה
**שם קובץ**: `01-login-screen.png`

**מה לצלם**:
- את המסך הראשוני של המערכת כשהיא נפתחת
- אם יש מסך נעילה/התחברות - צלם אותו
- אם המערכת נפתחת ישירות ללוח הבקרה - צלם את לוח הבקרה

**טיפים**:
- וודא שהחלון במצב מקסימלי
- אם יש לוגו - וודא שהוא נראה בבירור

---

## צילום מסך 2: לוח הבקרה המלא
**שם קובץ**: `02-dashboard-full.png`

**מה לצלם**:
- את כל לוח הבקרה כולל:
  - 4 הכרטיסיות הסטטיסטיות בחלק העליון
  - גרפים (אם קיימים)
  - טבלאות עם נתונים
  - כפתור ההתראות

**טיפים**:
- וודא שכל הכרטיסיות מכילות נתונים לדוגמה
- אם הדף ארוך - צלם את החלק העליון החשוב ביותר

## צילום מסך 3: חלון התראות
**שם קובץ**: `03-alerts-dialog.png`

**מה לצלם**:
- לחץ על כפתור ההתראות בלוח הבקרה
- צלם את החלון שנפתח עם רשימת ההתראות
- וודא שיש לפחות 2-3 התראות מסוגים שונים

**טיפים**:
- אם אין התראות - צור נתונים שיגרמו להתראות (הלוואה באיחור וכו')
- וודא שהחלון במרכז המסך

## שלב הבא: הוספת הצילומים למדריך

לאחר שצילמת את כל התמונות:

1. שמור את כל הקבצים בתיקייה `docs/images/`
2. פתח את הקובץ `docs/user-guide.html`
3. החלף כל `<div class="screenshot-placeholder">` בתג תמונה:

```html
<img src="images/01-login-screen.png" alt="מסך הכניסה" style="width: 100%; border-radius: 10px; box-shadow: 0 4px 8px rgba(0,0,0,0.1);">
```

4. שמור את הקובץ ופתח אותו בדפדפן לבדיקה

## טיפים נוספים

- **נתונים לדוגמה**: השתמש בשמות כמו "ישראל ישראלי", "משה כהן" וכו'
- **סכומים**: השתמש בסכומים עגולים כמו 1000, 5000, 10000
- **תאריכים**: השתמש בתאריכים קרובים לתאריך הנוכחי
- **ניקיון**: וודא שהמסך נקי מהתראות מערכת הפעלה או חלונות אחרים
- **גודל**: כל תמונה צריכה להיות לפחות 1280x720 פיקסלים
