| **היבט** | **אפיון מקורי (v1.0)** | **אפיון מעודכן (v2.0)** |

| **העברת הלוואה** | לא הוכרע | כן, עם audit log |
| **פירעונות** | לא הוזכר | יורשים fund_id מההלוואה |

| **הערכת זמן** | 11-18 שעות | 20-30 שעות (ריאלי יותר) |

## ✅ החלטות שהתקבלו

### 1. תרומות והפקדות
**החלטה**: שיוך לקופה (אופציה B)

**נימוק**: ללא שיוך אי אפשר לחשב "כסף זמין בקופה". האפיון המקורי דרש חישוב כזה, אז זה היה סתירה פנימית.

**השפעה**: הוספת 3 טבלאות נוספות למיגרציה.

---

### 2. העברות בין קופות
**החלטה**: לא בשלב 1, אבל תכנון מראש

**נימוק**: אם מחשבים יתרות כסכום תנועות (ולא ערך שמור), העברה בעתיד היא פשוט 2 תנועות.

**יתרון**: אפס עלות תכנונית עכשיו, קל מאוד להוסיף בעתיד.

---

### 3. העברת הלוואה בין קופות
**החלטה**: כן, עם רישום

**נימוק**: טעויות בבחירת קופה יקרו. עדיף לאפשר תיקון עם audit trail מאשר להכריח מחיקה ויצירה מחדש.

**יישום**: שדה "סיבה" חובה + `auditLog` service קיים.

---

### 4. מספר קופות צפוי
**החלטה**: טבלה (לא כרטיסים)

**נימוק**: 2-5 קופות צפויות. טבלה עובדת טוב גם ל-10 קופות. כרטיסים יפים אבל פחות מדרגיים.

## 🔧 שיפורים טכניים עיקריים

### מיגרציה חכמה
```typescript
// ❌ לפני (לולאה - איטי)
for (const loan of loans) {
  if (!loan.fund_id) {
    await loansService.update(loan.id, { fund_id: defaultFund.id })
  }
}

// ✅ אחרי (UPDATE אחד - מהיר)
await db.run(`UPDATE loans SET fund_id = ? WHERE fund_id IS NULL`, [defaultFund.id])
```

### אידמפוטנטיות
```typescript
// ✅ מיגרציה בטוחה להרצה חוזרת
const migrationKey = 'funds_migration_v1_completed'
if (localStorage.getItem(migrationKey)) {
  return // כבר רץ
}
// ... מיגרציה ...
localStorage.setItem(migrationKey, new Date().toISOString())
```

### גיבוי אוטומטי
```typescript
// ✅ לפני כל מיגרציה
await createBackup('pre-funds-migration')
// אם זה נכשל - העלה שגיאה ואל תמשיך
```

## 📋 חוקי עסק שנוספו

### 1. מחיקה מול השבתה
- **מחיקה**: רק אם אין **שום רשומות** (כולל soft-deleted)
- **השבתה**: מונעת הלוואות חדשות, מאפשרת פירעונות קיימים

### 2. קופת ברירת מחדל
- חייבת להיות תמיד
- אי אפשר להשבית/למחוק את האחרונה
- `setDefault()` = אטומית (all-or-nothing)

### 3. הלוואות מחזוריות
- יורשות `fund_id` מהתבנית
- עדכון ב-`recurringItemsService.ts`

### 4. חריגה מיתרה
- הצג אזהרה ❗
- אל תחסום ❌ (יש מצבים לגיטימיים)

### 5. עקביות
```typescript
// בדיקה אוטומטית
sum(all funds balances) === total balance
```
