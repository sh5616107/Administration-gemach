## איפה למצוא את הפיצ'ר?

### דרך 1: מכרטיס הלוואה
1. פתח מסך "ניהול הלוואות"
2. בחר הלוואה (לחץ על שורה בטבלה)
3. בפאנל שנפתח מימין → לחץ על טאב "עמלות"
4. לחץ "רישום תשלום עמלה +"

### דרך 2: מכרטיס לווה
1. פתח "ניהול הלוואות" → "לווים"
2. בחר לווה
3. בפאנל שנפתח → טאב "עמלות"
4. לחץ "רישום תשלום עמלה +"

### דרך 3: דוחות
1. תפריט עליון → "כלים מתקדמים"
2. גלול למטה לקטגוריה "דוחות"
3. לחץ על כפתור "דוח עמלות" 💰
