### 2. תיקון כפילות Audit ב-updateFeePaymentStatus ✅
**בעיה:** הפונקציה קראה ל-`updateFeePayment` שכבר רושם audit, ואז רשמה audit נוסף

**תוקן:**
- הפונקציה עכשיו עושה UPDATE ישיר ל-DB (ללא קריאה פנימית ל-updateFeePayment)
- רושמת רק audit **אחד** עם הפעולה `fee_payment_status_change`
- מונעת כפילות מוחלטת ברישום

**קוד:**
```typescript
// עדכון הסטטוס ישירות (ללא קריאה ל-updateFeePayment למניעת כפילות audit)
await db.run(
  'UPDATE fee_payments SET status = ?, updated_at = ? WHERE id = ?',
  [newStatus, new Date().toISOString(), id]
)

// רישום ב-Audit Log עם פעולה ייעודית
await logAudit('fee_payment_status_change', 'fee_payment', id, {
  before: { status: existing.status },
  after: { status: newStatus },
  metadata: reason ? { reason } : undefined,
  actor: 'מערכת'
})
```

### 4. אופטימיזציית N+1 ✅

**בעיה:** כל פונקציה טוענת מחדש את **כל** הלווים/הלוואות רק לצורך join

**תוקן:**
- הוספת **in-memory cache**: `borrowersCache`, `loansCache`
- פונקציות עזר חכמות: `getBorrowersMap()`, `getLoansMap()`
- שימוש ב-`Map.get()` במקום `Array.find()` (O(1) במקום O(n))
- ניקוי אוטומטי: `clearCache()` נקרא אחרי כל פעולת write

**קוד:**
```typescript
// Cache למניעת טעינה מיותרת (N+1)
let borrowersCache: Map<string, any> | null = null
let loansCache: Map<string, any> | null = null

async function getBorrowersMap(): Promise<Map<string, any>> {
  if (!borrowersCache) {
    const borrowers = await borrowersService.getAll()
    borrowersCache = new Map(borrowers.map(b => [b.id, b]))
  }
  return borrowersCache
}

function clearCache() {
  borrowersCache = null
  loansCache = null
}

// שימוש:
const borrowersMap = await getBorrowersMap()
const borrower = borrowersMap.get(fee.borrower_id)  // O(1)
```

**clearCache נקרא אחרי:**
- `createFeePayment`
- `updateFeePayment`
- `deleteFeePayment`
- `updateFeePaymentStatus`
