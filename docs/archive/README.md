# ארכיון תיעוד היסטורי

תיקייה זו מכילה מסמכי תיעוד היסטוריים מתהליך הפיתוח.

## מדיניות ארכוב

קבצים שמועברים לכאן:
- מסמכי SUMMARY מסשנים ישנים
- תיעוד ביניים של פיצ'רים שהושלמו
- אפיונים ישנים שמעורבבים כבר בקוד
- תיכנון וניתוח שכבר יושם

## מקור האמת

**במקום לחפש כאן**, השתמש ב:
- **`CHANGELOG.md`** - היסטוריית גרסאות ושינויים
- **`README.md`** - מדריך כללי למערכת
- **`docs/`** - תיעוד טכני עדכני
- **Git history** - היסטוריה מפורטת של כל שינוי

## קבצים בארכיון

מסודרים לפי קטגוריות:

### תיעוד סשנים
- `*_SUMMARY.md` - סיכומי סשנים
- `WORK_SESSION_*.md` - תיעוד עבודה

### פיצ'רים שהושלמו
- `*_FEATURE_SUMMARY.md` - סיכומי פיצ'רים
- `פיצ'ר_*.md` - אפיונים ויישומים בעברית

### תיקוני באגים
- `*_FIX_*.md` - תיעוד תיקונים
- `*_BUG_*.md` - ניתוח באגים

### מיגרציות וארכיטקטורה
- `UUID_*.md` - מיגרציית UUID
- `*_MIGRATION_*.md` - מסמכי מיגרציה
- `*_ANALYSIS.md` - ניתוחים טכניים

### תכנון ותיכנון
- `PROMPT_*.md` - הנחיות מערכת
- `*_PLAN.md` - תוכניות עבודה
- `INTEGRATION_*.md` - הזדמנויות אינטגרציה

---

**הערה:** קבצים אלה נשמרים להיסטוריה בלבד ואינם מתעדכנים.
