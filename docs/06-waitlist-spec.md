# מערכת תור להלוואות - מסמך אפיון

## מטרה
מערכת לניהול תור בקשות להלוואות, כך שכאשר הלוואה מתפנה (נפרעת), האדם הבא בתור יוכל לקבל אותה אוטומטית.

## תכונות עיקריות

### 1. הוספה לתור
- אפשרות להוסיף לווה לתור בקשת הלוואה
- שדות:
  - לווה (בחירה מרשימה)
  - סכום מבוקש
  - תאריך הבקשה (אוטומטי)
  - סוג הלוואה מועדף (קבועה/גמישה)
  - תקופה מבוקשת (חודשים)
  - הערות
  - עדיפות (רגילה/דחופה)

### 2. ניהול התור
- צפייה ברשימת כל הממתינים בתור
- **גרירה ושחרור (Drag & Drop)** - ניתן לגרור שורות עם העכבר לשינוי סדר התור
- עדכון פרטי בקשה
- מחיקת בקשה מהתור
- סינון לפי סטטוס (ממתין/בטיפול/אושר/נדחה)

### 3. התראות והתאמה
- כאשר הלוואה נפרעת במלואה - התראה על כסף זמין
- הצעה אוטומטית להתאים את הבקשה הבאה בתור
- בדיקת התאמה: האם הסכום הזמין מספיק לבקשה
- אפשרות לדלג על בקשה ולעבור לבאה בתור

### 4. יצירת הלוואה מהתור
- כפתור "אשר הלוואה" שיוצר הלוואה חדשה מהבקשה
- מעבר אוטומטי לטופס הלוואה עם הפרטים ממולאים
- סימון הבקשה כ"אושרה" בתור

## מבנה נתונים

### טבלת waitlist
```typescript
interface WaitlistEntry {
  id: number
  borrower_id: number
  requested_amount: number
  request_date: string
  loan_type: 'fixed' | 'flexible'
  requested_months?: number
  notes?: string
  priority: 'normal' | 'urgent'
  status: 'waiting' | 'processing' | 'approved' | 'rejected'
  position: number  // מיקום בתור
  created_at: string
  updated_at: string
}
```

## ממשק משתמש

### מיקום
טאב חדש בדף "ניהול לווים והלוואות" - "📋 תור בקשות"

### רכיבים
1. כפתור "הוסף לתור" - פותח דיאלוג
2. טבלת תור עם:
   - מספר בתור
   - שם לווה
   - סכום מבוקש
   - תאריך בקשה
   - עדיפות
   - סטטוס
   - פעולות (עריכה, מחיקה, העלאה, הורדה, אישור)
3. סטטיסטיקות:
   - סה"כ ממתינים
   - סכום כולל מבוקש
   - כסף זמין בגמ"ח

## התנהגות

### כאשר הלוואה נפרעת
1. בדיקה אם יש ממתינים בתור
2. הצגת התראה למשתמש
3. הצעה ליצור הלוואה לבא בתור
4. אם המשתמש מאשר - מעבר לטופס הלוואה חדשה

### ניהול סדר התור
- כפתורי ↑↓ להעלאה/הורדה במיקום
- גרירה ושחרור (drag & drop) - שלב עתידי
- שינוי עדיפות ל"דחופה" מעלה אוטומטית למעלה

## אינטגרציה

### עם הגדרות המערכת
- ניתן להסתיר/להציג את טאב תור ההלוואות דרך הגדרות המערכת
- ברירת מחדל: הטאב מוצג

### עם מערכת ההלוואות
- כאשר יוצרים הלוואה מהתור - עדכון סטטוס ל"אושרה"
- שמירת קישור בין ההלוואה לבקשה המקורית

### עם Dashboard
- הצגת מספר ממתינים בתור
- התראה על בקשות דחופות

### עם סטטיסטיקות
- דוח בקשות שאושרו/נדחו
- זמן המתנה ממוצע
