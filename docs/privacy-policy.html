מדיניות פרטיות – מינהל הגמ"ח (Administration Gemach)

עודכן לאחרונה:

"מינהל הגמ״ח" (Administration Gemach) היא אפליקציית שולחן עבודה בקוד פתוח לניהול גמ"ח כספים (הלוואות גמ"ח ללא ריבית). האפליקציה פועלת באופן מקומי במחשב המשתמש, ואינה כוללת שרת מרכזי שאוסף או מעבד את הנתונים שלך.

אילו נתונים האפליקציה ניגשת אליהם

האפליקציה מציעה אפשרות להתחבר עם חשבון Google לצורך שליחת מיילים מתוך האפליקציה (לדוגמה: שליחת אישור הלוואה לנמען). לשם כך האפליקציה מבקשת הרשאת Google אחת בלבד:

  • https://www.googleapis.com/auth/gmail.send — הרשאה לשליחת הודעות דוא"ל בשם המשתמש, בלבד. האפליקציה אינה קוראת, סורקת, מאחסנת או ניגשת בכל דרך אחרת לתוכן תיבת הדואר, אנשי הקשר, או כל נתון אחר בחשבון ה-Google של המשתמש.

כיצד נשמרים הנתונים

  • אסימון ההתחברות (access/refresh token) שמתקבל מ-Google נשמר באופן מקומי ומוצפן באמצעות מנהל האישורים המובנה של מערכת ההפעלה (Windows Credential Manager).
  • האסימון אינו נשלח, מועלה, או משותף עם כל שרת חיצוני, כולל מפתחי האפליקציה עצמם.
  • תוכן ההודעות שהמשתמש בוחר לשלוח (לדוגמה טקסט מסמך הלוואה) מועבר ישירות מהמחשב של המשתמש אל שרתי Google לצורך השליחה, ואינו נשמר או מועבר לשום גורם שלישי.
  • כלל הנתונים העסקיים של הגמ"ח (לווים, הלוואות, החזרים וכו') נשמרים אך ורק באופן מקומי על גבי המחשב של המשתמש, ואינם מועלים לשום שרת.

שיתוף נתונים עם צדדים שלישיים

האפליקציה אינה משתפת, מוכרת, או מעבירה נתוני משתמשים לשום צד שלישי. השימוש היחיד בהרשאת Google הוא שליחת הודעת דוא"ל יזומה על ידי המשתמש עצמו, דרך שרתי Gmail של Google.

ביטול גישה

ניתן לבטל את הגישה של האפליקציה לחשבון ה-Google בכל עת דרך עמוד ההרשאות של חשבון Google, וכן למחוק את האסימון השמור מקומית דרך הגדרות האפליקציה.

Privacy Policy – Administration Gemach

Last updated:

"Administration Gemach" is an open-source desktop application for managing a Jewish charitable free-loan fund (gemach). The application runs locally on the user's computer and has no central server that collects or processes user data.

What data the application accesses

The application offers an optional "Sign in with Google" feature used solely to send emails from within the app (for example, sending a loan confirmation to a recipient). For this it requests a single Google permission:

  • https://www.googleapis.com/auth/gmail.send — permission to send email messages on the user's behalf only. The application does not read, scan, store, or otherwise access the user's inbox content, contacts, or any other data in the user's Google account.

How data is stored

  • The authentication token (access/refresh token) received from Google is stored locally, encrypted via the operating system's built-in credential store (Windows Credential Manager).
  • The token is never transmitted to, uploaded to, or shared with any external server, including the application's own developers.
  • Message content the user chooses to send (e.g. loan document text) is transmitted directly from the user's computer to Google's servers for delivery, and is not stored or passed to any third party.
  • All of the gemach's business data (borrowers, loans, repayments, etc.) is stored only locally on the user's computer and is never uploaded to any server.

Third-party data sharing

The application does not share, sell, or transfer user data to any third party. The only use of the Google permission is sending an email explicitly initiated by the user, through Google's own Gmail servers.

Revoking access

Access can be revoked at any time via the Google Account permissions page, and the locally stored token can be deleted through the application's settings.

Contact

Questions about this policy can be directed via the project's GitHub page.
