## חוסר FundSelector ב-UnifiedLoansPage

UnifiedLoansPage הוא הדף הראשי לניהול הלוואות (הדף שנפתח בלחיצה על "הלוואות" בתפריט). הדף בנוי כך:
- אזור חיפוש ובחירת לווה (Autocomplete)
- פרופיל הלווה מימין (30%)
- כרטיסי הלוואות משמאל (70%)
- לחיצה על "הלוואה חדשה" / כרטיס הלוואה פותחת LoanSidePanel (Drawer)

**LoanSidePanel** עוטף את **LoansTab** ומוסיף לו טאבים (פרטי הלוואה, עמלות, קבצים), אבל:
- UnifiedLoansPage לא מגדיר `selectedFundId` ב-state שלו בכלל
- UnifiedLoansPage לא קורא ל-`fundsService.getDefault()` בשום מקום
- LoanSidePanel לא מקבל prop של `fund_id` או `selectedFundId` מ-UnifiedLoansPage
- LoanSidePanel לא מעביר שום prop קשור ל-fund_id ל-LoansTab שבתוכו

התוצאה: LoansTab רץ עם `initialFundId={undefined}`, והוא אמנם מאתחל את ה-fund_id בעצמו ב-handleNewLoan (קריאה ל-getDefault), אבל זה לא עובד בעת עריכה — כשפותחים הלוואה קיימת דרך LoanSidePanel, ה-fund_id של ההלוואה לא מועבר ל-FundSelector.

בפועל, LoansTab עושה זאת:
```typescript
const [selectedFundId, setSelectedFundId] = useState<string>('')
```

וב-`handleNewLoan`:
```typescript
const { fundsService } = await import('../../services/database')
const defaultFund = await fundsService.getDefault()
setSelectedFundId(defaultFund.id)
```

וב-`useEffect` שמטפל ב-`selectedLoan` (עריכה):
```typescript
useEffect(() => {
  if (selectedLoan?.id) {
    loadRepayments(selectedLoan.id)
    setFormData(selectedLoan)
  } else {
    // ...
  }
}, [selectedLoan, settings.default_loan_type])
```

הבעיה: `setFormData(selectedLoan)` מעתיק את כל שדות ההלוואה כולל `fund_id`, אבל **לא קורא ל-`setSelectedFundId`**. המשמעות: FundSelector מוצג ריק בעת עריכה, כי ה-prop `value={selectedFundId}` מקבל string ריק.

## Deposits.tsx — דפוס מלא ועקבי

Deposits.tsx מיישם את הדפוס הנכון:

1. **State מוגדר בראש הקובץ:**
   ```typescript
   const [selectedFundId, setSelectedFundId] = useState<string>('');
   ```

2. **אתחול ברירת מחדל ב-handleOpenNewDeposit:**
   ```typescript
   const handleOpenNewDeposit = async () => {
     setActiveDeposit(null);
     // ...
     try {
       const { fundsService } = await import('../services/database');
       const defaultFund = await fundsService.getDefault();
       setSelectedFundId(defaultFund.id);
     } catch (error) {
       console.error('Error loading default fund:', error);
       setSelectedFundId('');
     }
     // ...
   }
   ```

3. **טעינת fund_id מההפקדה הקיימת ב-handleOpenDeposit:**
   ```typescript
   const handleOpenDeposit = (deposit: Deposit) => {
     setActiveDeposit(deposit);
     setDepositForm({ /* ... */ });
     setSelectedFundId((deposit as any).fund_id || '');
     // ...
   }
   ```

4. **העברת fund_id ל-create/update:**
   ```typescript
   const handleSaveDeposit = async () => {
     // ...
     const insertFields = ['depositor_id', 'amount', 'deposit_date', 'notes'];
     const insertPlaceholders = ['?', '?', '?', '?'];
     const insertValues: any[] = [selectedDepositor.id, depositForm.amount, depositForm.deposit_date, depositForm.notes];
     
     if (selectedFundId) {
       insertFields.push('fund_id');
       insertPlaceholders.push('?');
       insertValues.push(selectedFundId);
     }
     
     await db.run(
       `INSERT INTO deposits (${insertFields.join(', ')}) VALUES (${insertPlaceholders.join(', ')})`,
       insertValues
     );
   }
   ```

5. **FundSelector מוצג בטופס:**
   ```typescript
   <FundSelector
     value={selectedFundId}
     onChange={setSelectedFundId}
     required={false}
   />
   ```

Deposits.tsx עובר את כל 5 הצעדים. Donations.tsx עובר את כולם גם. **UnifiedLoansPage חסר לחלוטין.**
