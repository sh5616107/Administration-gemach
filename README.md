# מינהל הגמ"ח

מערכת מודרנית לניהול גמ"ח כספים, מיועדת למחשבי Windows.

**גרסה נוכחית: 4.0.5**

## תכונות עיקריות

- 📊 **דף הבית** - סטטיסטיקות, כסף זמין, לווים פעילים, התראות חכמות
- 👤 **ניהול לווים** - הוספה, עריכה, חיפוש, היסטוריית הלוואות
- 🤝 **ניהול ערבים** - מעקב ערבויות, סטטוסים, הלוואות לערבים
- 💰 **ניהול הלוואות** - הלוואות קבועות/גמישות, מחזוריות, פירעון אוטומטי
- ✏️ **עריכת פריטים מחזוריים** - עריכה מאוחדת של הלוואות, פירעונות והפקדות מחזוריות
- 🎁 **תרומות** - רישום תורמים ותרומות
- 📥 **הפקדות** - ניהול מפקידים והפקדות מחזוריות
- 📅 **לוח שנה** - תצוגת אירועים עברית/לועזית, חיפוש מתקדם
- 📄 **הפקת מסמכים** - שטרי הלוואה, קבלות, דוחות
- 🛠️ **כלים מתקדמים** - גיבוי/שחזור, יבוא/יצוא אקסל, רשימה שחורה, הוצאות
- 🔒 **הגנה** - נעילת מערכת עם סיסמה

## טכנולוגיות

- React 18 + TypeScript
- Material-UI v5
- Tauri 2.0 (Rust)
- SQLite (sql.js)
- jsPDF + html2canvas
- xlsx (יבוא/יצוא אקסל)

## התקנה

```bash
npm install
```

## הרצה בפיתוח

```bash
npm run tauri:dev
```

## בנייה להפצה

```bash
npm run tauri:build
# או
.\build.ps1
```

קובץ ההתקנה יווצר בתיקיית `release`.

## מבנה הפרויקט

```
├── docs/                    # מסמכי אפיון ועיצוב
├── src/
│   ├── components/          # רכיבי React
│   │   ├── calendar/        # לוח שנה
│   │   ├── donations/       # תרומות והפקדות
│   │   └── loans/           # לווים, ערבים, הלוואות
│   ├── hooks/               # React hooks
│   ├── pages/               # דפי האפליקציה
│   ├── services/            # שירותים (DB, מסמכים, אקסל)
│   ├── utils/               # פונקציות עזר
│   └── __tests__/           # בדיקות
├── src-tauri/               # קוד Tauri (Rust)
├── release/                 # קבצי הפצה
├── index.html
├── package.json
└── vite.config.ts
```
