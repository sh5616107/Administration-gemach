# מינהל הגמ"ח

מערכת מודרנית לניהול גמ"ח כספים, מיועדת למחשבי Windows.

**גרסה נוכחית: 4.5.0**

## תכונות עיקריות

- 📊 **דף הבית** - סטטיסטיקות, כסף זמין, לווים פעילים, התראות חכמות
- 👤 **ניהול לווים** - הוספה, עריכה, חיפוש, היסטוריית הלוואות
- 🤝 **ניהול ערבים** - מעקב ערבויות, סטטוסים, הלוואות לערבים
- 💰 **ניהול הלוואות** - הלוואות קבועות/גמישות, מחזוריות, פירעון אוטומטי
- ✏️ **עריכת פריטים מחזוריים** - עריכה מאוחדת של הלוואות, פירעונות והפקדות מחזוריות
- 👥 **אנשי קשר מאוחדים** - חיפוש ותצוגה מאוחדים של לווים, ערבים, תורמים ומפקידים
- 🎁 **תרומות** - רישום תורמים ותרומות
- 📥 **הפקדות** - ניהול מפקידים והפקדות מחזוריות
- 📅 **לוח שנה** - תצוגת אירועים עברית/לועזית, חיפוש מתקדם
- 📄 **הפקת מסמכים** - שטרי הלוואה, קבלות ודוחות כ-PDF
- 🛠️ **כלים מתקדמים** - גיבוי/שחזור, יבוא/יצוא אקסל, רשימה שחורה, הוצאות, דוחות תקופתיים
- 🌐 **ריבוי שפות** - ממשק בעברית (ברירת מחדל) ובאנגלית
- 🔄 **עדכונים אוטומטיים** - בדיקת גרסה חדשה מול GitHub Releases והתקנה בלחיצה
- 🔒 **הגנה** - נעילת מערכת בסיסמה (מאוחסנת כ-hash מסוג SHA-256 + salt)

## 🚧 בפיתוח

תכונות שהקוד שלהן קיים בריפו אך עדיין לא זמינות (או מוסתרות) למשתמש הקצה:

- **מסגרת מסמך מותאמת אישית** - העלאת PNG כמסגרת/לוגו קבוע לכל המסמכים, עם שוליים מתכווננים. הוסרה זמנית בגרסה 4.4.12 עקב בעיות אמינות בהדפסה; המסמכים חזרו למנגנון `printHtml()` היציב עם לוגו רגיל. מתוכננת לחזור לאחר פתרון מקיף של מנגנון ה-PDF.
- **סנכרון בנקים** (`israeli-bank-scrapers`, דרך sidecar נפרד ב-Node.js) - הדפים והשירותים קיימים תחת `src/pages/bank`, אך התפריט מוסתר ב-`Layout.tsx` עד להשלמת הפיתוח.

## טכנולוגיות

- React 18 + TypeScript
- Material-UI v5
- Tauri 2 (Rust)
- אחסון מקומי - JSON + localforage (ללא שרת/DB חיצוני)
- jsPDF + html2canvas - הפקת PDF
- xlsx - יבוא/יצוא אקסל
- i18next - ריבוי שפות (עברית/אנגלית)
- @hebcal/core - חישובי לוח עברי

## דרישות מוקדמות

- [Node.js](https://nodejs.org)
- [Rust](https://rustup.rs) - נדרש לפיתוח ולבנייה עם Tauri

## התקנה

```bash
npm install
```

## הרצה בפיתוח

```bash
npm run tauri:dev
```

לתצוגה מקדימה בדפדפן בלבד (ללא חלון native, לא דורש Rust מותקן):

```bash
npm run dev
```

## בדיקות

```bash
npm test
```

## בנייה להפצה

```bash
npm run tauri:build
# או, כולל בניית ה-sidecar לסנכרון בנקים:
.\build.ps1
```

קובץ ההתקנה (NSIS, Windows בלבד) יווצר בתיקיית `release`.
לבנייה מלאה יש לבנות קודם גם את ה-sidecar: `cd sidecar && npm install && npm run build` (אחרת נארז binary placeholder ריק) - פרטים ב-`sidecar/README.md`.

## מבנה הפרויקט

```
├── docs/                      # מסמכי אפיון, עיצוב והיסטוריית פיתוח
├── sidecar/                   # תהליך Node.js נלווה לסנכרון בנקים (israeli-bank-scrapers)
├── src/
│   ├── components/            # רכיבי React (bank, calendar, contacts, donations, loans, recurring)
│   ├── i18n/                  # תרגומים (he/en)
│   ├── hooks/                 # React hooks
│   ├── pages/                 # דפי האפליקציה
│   ├── services/              # שירותים (אחסון, מסמכים, אקסל, בנקים)
│   ├── utils/                 # פונקציות עזר
│   └── __tests__/             # בדיקות
├── src-tauri/                 # קוד Tauri (Rust)
├── release/                   # קבצי הפצה (נוצר בבנייה, לא נשמר ב-git)
├── index.html
├── package.json
└── vite.config.ts
```
